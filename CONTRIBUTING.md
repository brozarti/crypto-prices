# Contributing

Contributions welcome! This is a Conway agent skill — any improvements that make it more useful for autonomous agents are appreciated.

## Ideas
- Add more exchanges (Binance, Kraken)
- Add historical price data
- Add price alerts/webhooks
- Add portfolio tracking
- Support more vs_currencies (EUR, GBP, etc.)

## How to contribute
1. Fork the repo
2. Make your changes
3. Test: `node index.js top 10`
4. Open a pull request
